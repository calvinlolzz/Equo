# 分帳 APP 產品規劃

## 1. 產品定位

打造一款適合朋友聚餐、旅遊、家庭、室友與公司聚會使用的分帳 APP。核心目標是讓使用者只需要記錄支出，系統自動完成分攤、計算、結算與收款。

核心價值：

- 快速記帳：3 步內建立一筆支出。
- 自動分攤：支援平均、指定成員、權重、自訂金額。
- 最少轉帳：自動產生最少筆數的結算建議。
- 即時提醒：清楚顯示誰該付、誰已付、誰逾期。
- iOS 質感：採用液態毛玻璃、半透明層次、柔和動效與清晰資訊階層。

## 2. 目標使用情境

1. 聚餐分帳：多人聚餐後快速建立帳目並分享 LINE 結算結果。
2. 旅遊分帳：跨天、多幣別、多筆費用，最後自動結算。
3. 室友生活費：房租、水電、網路費等固定帳單每月自動產生。
4. 家庭帳務：家長管理家庭共同開支，子女只能查看個人應付。
5. 公司活動：多人活動支出透明化，付款狀態可追蹤。

## 3. 核心功能規劃

### 3.1 群組管理

功能：

- 建立群組。
- 修改群組名稱、圖片、幣別與預設分攤方式。
- 邀請成員加入。
- 產生邀請連結與 QR Code。
- 成員權限管理。
- 群組封存。

角色：

- 擁有者：可管理群組、成員、刪除資料。
- 管理員：可新增帳目、邀請成員、結算。
- 成員：可新增自己的支出與查看帳務。
- 訪客：只能查看被分享的結算結果。

### 3.2 支出紀錄

欄位：

- 項目名稱。
- 金額。
- 幣別。
- 付款人。
- 消費日期。
- 分類：餐飲、住宿、交通、娛樂、購物、其他。
- 備註。
- 發票或收據照片。
- 參與分攤成員。
- 分攤方式。

體驗要求：

- 首頁提供浮動新增按鈕。
- 支援拍照新增、手動新增、自然語言新增。
- 建立完成後立即顯示此筆費用造成的應收應付變化。

### 3.3 分攤方式

1. 平均分攤：所有參與者平均分擔。
2. 指定成員分攤：只有指定成員參與。
3. 權重分攤：依比例或份數分擔，例如爸爸 40%、媽媽 30%。
4. 自訂金額：每位成員輸入不同金額。
5. 排除成員：群組成員可不參與特定支出。
6. 付款人多人化：允許多人先墊付同一筆費用。

檢核規則：

- 自訂金額總和必須等於支出金額。
- 權重總和可用比例或份數，自動換算。
- 若金額無法整除，最小單位差額由系統自動分配並顯示。

### 3.4 自動最佳化結算

功能：

- 計算每位成員的淨額。
- 正數代表應收，負數代表應付。
- 系統產出最少轉帳筆數。
- 可標記付款完成。
- 可重新計算未付款項。

結算結果顯示：

- 「小明 應收 500 元」。
- 「小華 轉帳 300 元給小明」。
- 「小美 轉帳 200 元給小明」。

### 3.5 LINE 分享

功能：

- 一鍵分享結算摘要。
- 分享群組邀請連結。
- 分享單筆付款提醒。
- 分享付款連結。

分享內容應包含：

- 群組名稱。
- 結算日期。
- 轉帳清單。
- 付款狀態。
- APP 深連結。

### 3.6 多幣別

支援：

- TWD、USD、JPY、KRW、EUR。
- 群組預設幣別。
- 每筆支出可選不同幣別。
- 即時匯率換算。
- 旅遊結束後以群組主幣別結算。

### 3.7 統計分析

圖表：

- 月支出分析。
- 年支出分析。
- 類別比例。
- 成員支出排行。
- 群組總花費趨勢。

適合畫面：

- 群組內的「分析」分頁。
- 個人首頁的「我的本月支出」。

### 3.8 固定帳單

適用項目：

- 房租。
- 水費。
- 電費。
- 網路費。
- 停車費。

功能：

- 每月自動建立帳單。
- 可設定固定付款人。
- 可設定提醒日期。
- 可暫停或跳過單月。

### 3.9 付款提醒

通知方式：

- App Push。
- Email。
- LINE Notify 或 LINE 分享提醒。

提醒規則：

- 結算後未付款提醒。
- 到期日前提醒。
- 逾期提醒。
- 收款人手動催款。

### 3.10 AI 功能

AI 發票辨識：

- 拍照辨識店家名稱、消費項目、總金額與日期。
- 自動建議分類。
- 可讓使用者確認後建立支出。

AI 自然語言記帳：

- 使用者輸入「今天聚餐 4200 元，阿華付款，4 人平均」。
- 系統解析金額、付款人、日期、分攤方式與參與者。
- 建立前提供確認畫面。

### 3.11 行動支付整合

支援方向：

- LINE Pay。
- 街口支付。
- 全支付。
- Apple Pay。
- Google Pay。

功能：

- 一鍵付款。
- 一鍵收款。
- 付款紀錄同步。
- 服務費抽成。

初期可先以「付款連結與付款狀態追蹤」替代完整金流串接，降低 MVP 複雜度。

## 4. 資訊架構

底部 Tab 建議：

1. 首頁：我的群組、待付款、待收款。
2. 群組：所有分帳群組。
3. 新增：快速新增支出或掃描發票。
4. 統計：個人與群組支出分析。
5. 我的：帳號、訂閱、付款方式、設定。

群組內分頁：

1. 動態：支出流水與成員操作紀錄。
2. 結算：目前誰欠誰多少。
3. 分析：圖表與排行。
4. 成員：邀請、權限、付款狀態。
5. 設定：幣別、固定帳單、通知。

## 5. 主要畫面規劃

### 5.1 啟動畫面

- 全螢幕液態玻璃背景。
- APP Logo 置中。
- 進入後以柔和縮放與模糊轉場到首頁。

### 5.2 首頁

內容：

- 頂部顯示問候語與個人總覽。
- 半透明總覽卡：待付款、待收款、本月花費。
- 群組列表。
- 最近支出。
- 右下浮動新增按鈕。

iOS 風格：

- 背景使用淡色漸層與模糊色塊。
- 卡片採用 `blur`、半透明白、細邊框與柔和陰影。
- 互動元件以圓角、輕彈回饋與短動畫呈現。

### 5.3 群組詳情

內容：

- 群組封面與成員頭像堆疊。
- 目前結算摘要。
- 支出流水列表。
- 分頁切換：動態、結算、分析、成員。

重點：

- 使用者一進群組就能看見「我該付多少」或「我該收多少」。
- 結算建議要清楚、可分享、可標記完成。

### 5.4 新增支出

流程：

1. 輸入項目與金額。
2. 選付款人與參與成員。
3. 選分攤方式。
4. 預覽每人金額。
5. 建立。

進階入口：

- 拍發票。
- AI 文字輸入。
- 多幣別切換。
- 新增備註與照片。

### 5.5 結算畫面

內容：

- 應付與應收切換。
- 最少轉帳清單。
- 每筆轉帳的付款狀態。
- LINE 分享按鈕。
- 付款連結按鈕。

狀態：

- 未付款。
- 已提醒。
- 已付款待確認。
- 已完成。

### 5.6 統計畫面

內容：

- 本月總支出。
- 類別圓餅圖或環形圖。
- 每日支出折線圖。
- 成員排行。
- 支出分類篩選。

### 5.7 我的設定

內容：

- 個人資料。
- 預設幣別。
- 通知設定。
- 付款方式。
- Premium 訂閱。
- 匯出 Excel / PDF。

## 6. 視覺設計方向：iOS 液態毛玻璃

### 6.1 整體感覺

關鍵詞：

- Liquid Glass。
- Frosted Glass。
- Light depth。
- Soft motion。
- Native iOS。
- Clean finance UI。

畫面不做厚重商業後台感，而是接近 iOS 原生 App、Apple Wallet、Apple Fitness 與 iOS 26 液態玻璃方向的輕盈層次。

### 6.2 色彩

主色：

- Apple Blue：`#0A84FF`。
- Mint Green：`#30D158`。
- Soft Purple：`#BF5AF2`。

輔色：

- 背景淺灰：`#F5F7FA`。
- 玻璃白：`rgba(255, 255, 255, 0.62)`。
- 邊框白：`rgba(255, 255, 255, 0.48)`。
- 文字深色：`#1C1C1E`。
- 次要文字：`#6E6E73`。
- 警示紅：`#FF453A`。

### 6.3 元件樣式

卡片：

- 半透明背景。
- 背景模糊 20-32px。
- 1px 半透明邊框。
- 16-24px 圓角。
- 輕量陰影。

按鈕：

- 主要按鈕使用高飽和藍色。
- 次要按鈕使用玻璃膠囊形。
- 付款、收款、分享使用 icon + 文字。

列表：

- 使用 iOS grouped list 風格。
- 每列顯示頭像、項目、日期、金額與狀態。
- 金額正負用顏色區分。

互動：

- 點擊卡片時微縮放。
- Modal 使用底部 sheet。
- 新增支出用半高 sheet 或全螢幕表單。
- 分頁切換使用滑動動畫。

### 6.4 字體與排版

- iOS 使用 San Francisco。
- Web 或跨平台可用 `-apple-system, BlinkMacSystemFont, "SF Pro Display", "Segoe UI"`。
- 大標題 28-34px。
- 卡片標題 17-20px。
- 內文 15-17px。
- 輔助文字 12-14px。

## 11. 商業模式

免費版：

- 最多 3 個群組。
- 基本分帳。
- 基本結算。
- 廣告顯示。

Premium：

- 無限群組。
- AI 發票辨識。
- AI 記帳助手。
- 多幣別。
- Excel 匯出。
- PDF 報表。
- 進階統計。
- 無廣告。

金流抽成：

- 使用 APP 內付款連結或整合支付時收取 1% 服務費。

## 12. 開發建議

若要快速做 MVP，建議使用：

- 前端：React Native 或 Flutter。
- 後端：Node.js / NestJS 或 Firebase。
- 資料庫：PostgreSQL 或 Firestore。
- 圖片儲存：Firebase Storage 或 S3。
- 通知：Firebase Cloud Messaging。
- 登入：Apple、Google、Email。

若主打 iOS 質感並優先上架 iPhone，可考慮：

- SwiftUI。
- CloudKit 或 Firebase。
- Apple Sign in。
- Apple Push Notification。

## 13. 成功指標

產品指標：

- 建立一筆支出平均時間少於 20 秒。
- 使用者能在 1 分鐘內完成群組建立、邀請與第一筆分帳。
- 結算結果能在 1 次點擊內分享。
- 群組結算轉帳筆數明顯少於原始互欠筆數。

商業指標：

- 免費用戶轉 Premium 比例。
- 每個群組平均支出筆數。
- LINE 分享帶來的新用戶數。
- AI 功能使用率。
