# Equo 算好設計優化建議書

> 產出標記：GPT-5.5 高的產出
> 評估目標：將目前設計從約 7.6 / 10 優化到最接近 10 / 10 的產品版本
> 評估立場：只採用 GPT-5.5 的主觀設計判斷，不追求功能全塞，而是追求「一看就懂、一用就順、願意留下」

---

## 一、目前整體評分

目前版本評分：**7.6 / 10**

### 評分原因

Equo 算好目前已經具備很完整的分帳 App 雛形，功能量非常足夠，包含：

* 免登入先使用
* Email / Apple / Google 登入
* 群組分帳
* 新增支出
* 成員管理
* 最少轉帳
* 結算分享
* 群組分析
* AI 記帳助手
* Excel / PDF 匯出
* 付款方式
* 固定帳單
* 家庭模式
* 自動化提醒

這些功能讓產品看起來不像簡單 Demo，而是已經有完整產品藍圖。

但目前最大的問題是：**功能很多，主流程不夠聚焦。**

使用者第一次打開時，會看到很多資訊，但不一定會馬上知道：

1. 我現在要先建立群組嗎？
2. 我可以直接新增支出嗎？
3. 我需不需要登入？
4. 這個 App 最強的賣點是什麼？
5. 我為什麼要用它，而不是用 Splitwise、Excel 或 LINE 群組？

因此目前比較像「功能展示型原型」，還差一步變成「高完成度產品介面」。

---

## 二、最接近 10 分的產品定位

我認為 Equo 算好最接近 10 分的定位應該是：

> **不用登入也能先算，AI 幫你快速記帳，需要備份與邀請時再登入的輕量分帳 App。**

這個定位比「完整分帳系統」更好。

因為一般人使用分帳 App 的當下，多半是在：

* 剛吃完飯
* 剛訂完房
* 旅遊途中
* 室友要算水電
* 有人先墊錢
* 大家在 LINE 裡問「誰欠誰多少」

這時候使用者最不想看到的是：

* 複雜註冊
* 一堆設定
* 付款方式
* 報表
* 權限管理
* 自動化規則

使用者真正想要的是：

> **我花多少、誰付錢、誰要分、最後誰轉給誰。**

所以最接近 10 分的版本，應該把產品收斂成一個超清楚的核心：

> **30 秒新增一筆支出，10 秒知道誰該轉給誰。**

## 三、最接近 10 分的首頁版本

### 目前首頁問題

目前首頁資訊很多，但空資料時會出現大量 `$0`，例如：

* 今日狀態 $0
* 待付款 $0
* 待收款 $0
* 群組總花費 $0
* 我的狀態 $0

這會讓畫面顯得冷，而且不像一個正在引導新手的 App。

## 五、最接近 10 分的底部導覽

我建議底部導覽只保留 4 個主入口：

```txt
首頁｜群組｜新增｜統計｜我的
```

但視覺權重應該是：

```txt
首頁｜群組｜＋｜統計｜我的
```

中間的「＋」要最明顯，因為分帳 App 的核心行為就是新增支出。

### 建議權重

| 頁籤 | 重要性 | 說明              |
| -- | --: | --------------- |
| 首頁 |   高 | 看待付款、待收款、最近群組   |
| 群組 |   高 | 管理旅遊、聚餐、室友、家庭分帳 |
| 新增 |  最高 | App 最核心行為       |
| 統計 |   中 | 看花費分析與報表        |
| 我的 |   低 | 設定、備份、登入、付款方式   |

## 六、新增支出頁：應該成為產品主賣點

目前新增支出頁已經有 AI 記帳助手，這是非常大的亮點。

但它現在比較像其中一個功能區塊，沒有被設計成主角。

### 我認為最接近 10 分的新增支出頁應該是：

```txt
新增支出

AI 快速填寫

[ 今天聚餐 4200 元，阿華付款，4 人平均分攤 ]

[解析文字] [掃描發票]

或手動輸入

金額
項目名稱
付款人
分攤成員

更多設定
- 群組
- 幣別
- 分類
- 分攤方式
- 備註

預覽分攤

阿華 先付 $4,200
每人分攤 $1,050

小美 要給阿華 $1,050
阿明 要給阿華 $1,050
小陳 要給阿華 $1,050

[確認建立]
```

### 關鍵原則

新增支出頁不要讓使用者一開始就看到太多欄位。

應該是：

1. AI 先填
2. 手動可改
3. 更多設定收合
4. 最後給清楚預覽
5. 再確認建立

這樣會比傳統表單更有產品感。

## 七、空狀態設計建議

目前空資料狀態偏冷，建議全部改成「有情境的空狀態」。

### 首頁空狀態

```txt
還沒有支出

和朋友聚餐、旅遊、室友分帳時，
可以從第一筆支出開始。

[新增第一筆支出]
```

### 群組空狀態

```txt
還沒有群組

你可以先建立一個聚餐、旅遊、室友或家庭群組，
之後每筆支出都會自動算清楚。

[建立第一個群組]
```

### 統計空狀態

```txt
還沒有統計資料

新增幾筆支出後，
這裡會顯示類別花費、成員墊付與幣別分布。

[新增支出]
```

### 結算空狀態

```txt
目前都算清

沒有待付款，也沒有人欠你錢。
這是最舒服的狀態。

[分享目前狀態]
```

## 八、設定頁應該拆層

目前「我的」頁功能太多，容易變成後台。

建議拆成 4 個區塊：

### 1. 帳號

```txt
帳號
- 登入 / 登出
- Email
- 頭像
- 暱稱
```

### 2. 偏好設定

```txt
偏好設定
- 夜間模式
- 預設幣別
- 語言
```

### 3. 資料管理

```txt
資料管理
- 立即備份
- 載入備份
- 查看備份
- 重設資料
```

### 4. 進階功能

```txt
進階功能
- 匯出報表
- 付款方式
- 付款紀錄
- 固定帳單
- 家庭模式
- 日程表自動建群組
- 通知設定
```

### 設計原則

「我的」頁第一眼只放常用設定。

付款、報表、自動化、家庭模式全部收進「進階功能」，不要一開始就全部攤開。

## 九、功能優先級建議

### 第一優先：一定要做好

| 功能    | 原因           |
| ----- | ------------ |

| 新增支出  | App 核心行為     |

| 分享結算  | 最容易產生傳播      |
| 免登入使用 | 降低門檻         |
| 登入備份  | 增加留存         |

### 第二優先：做得好會加分

| 功能             | 原因             |
| -------------- | -------------- |
| AI 記帳助手        | 差異化主賣點         |
| 掃描發票           | 增強便利性          |

## 十、視覺設計建議

### 目前視覺方向

目前整體乾淨、偏工具型，沒有太多干擾。

但還可以再提升「溫度」與「品牌感」。

### 建議風格

```txt
乾淨、輕量、可信任、有一點可愛，但不要太幼稚。
```

### 色彩建議

主色可以用：

```txt
主色：#2563EB 或 #0EA5E9
輔色：#F8FAFC
成功：#22C55E
提醒：#F59E0B
危險：#EF4444
文字：#0F172A
次文字：#64748B
```

但整體不要太藍白制式，可以加入一點暖色讓它更像生活工具。

### 卡片設計

首頁卡片建議只保留 3 種：

```txt
待付款
待收款
最近群組
```

不要讓首頁過早出現太多分析型資料。

### CTA 設計

主按鈕文案建議：

```txt
新增支出
建立群組
查看結算
分享結算
確認建立
```

避免太多同層級按鈕，例如：

```txt
更新
同步
查看導覽
清除範例
檢查資料狀態
```

這些按鈕要降低權重，避免使用者不知道該點哪個。

## 十一、最接近 10 分的使用者流程

### 情境：四個朋友吃飯

```txt
1. 使用者打開 App
2. 不用登入
3. 點「新增支出」
4. 輸入：「今天聚餐 4200 元，阿華付款，4 人平均分攤」
5. AI 自動填表
6. 使用者確認分攤預覽
7. 建立支出
8. 系統顯示誰該付給誰
9. 一鍵複製結算文字
10. 貼到 LINE 群組
```

### 這個流程要控制在 30 秒內完成

這是 Equo 算好最應該追求的核心體驗。

> **Equo 算好是一個不用登入就能先開始的 AI 分帳工具，讓你用一句話新增支出，自動算出誰該付給誰，最後一鍵分享給朋友。**

## 十三、建議改版順序

### 第 1 階段：先把主流程打磨好

* 首頁強化「新增支出」
* 空狀態改成引導式文案
* 新增支出頁把 AI 記帳助手放到最上方
* 預覽分攤做得更清楚
* 分享結算文案變好讀

### 第 2 階段：整理資訊架構

* 設定頁拆層
* 進階功能收合
* 報表與付款降低初始權重
* 家庭模式移到進階功能
* 自動化移到進階功能

### 第 3 階段：強化品牌與信任感

* 加入資料保存說明
* 加入「此裝置資料」提醒
* 登入備份文案更清楚
* 加入隱私與資料安全入口
* 加入匯出與刪除資料說明

### 第 4 階段：做出差異化

* AI 記帳助手
* 發票掃描
* LINE 分享結算
* 多幣別旅遊模式
* 室友固定帳單模式

---

## 十四、最終建議總結

目前 Equo 算好不是設計不好，而是「功能想得太完整」，導致第一眼有一點分散。

最接近 10 分的做法不是再加功能，而是反過來收斂：

```txt
首頁只問：今天要結哪一筆？
新增只做：一句話快速記帳
結算只給：誰該轉給誰
分享只要：一鍵貼到 LINE
登入只在：需要備份與邀請時出現
```

只要把這五件事做到極順，Equo 算好就會從「功能完整的原型」變成「真的有人會想每天使用的分帳 App」。

我的最終理想分數：

```txt
目前版本：7.6 / 10
完成第一階段：8.4 / 10
完成第二階段：8.8 / 10
完成第三階段：9.1 / 10
完成第四階段：9.4 / 10
真正接近 10 分版本：9.6 / 10
```

10 分不是功能最多，而是使用者在最混亂的分帳情境下，仍然能很快把錢算清楚。
