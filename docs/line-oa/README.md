## 文字指令（不在圖文選單上）

圖文選單維持上表 A–F 不變；下面這些直接在聊天室傳文字。

| 用途 | 指令範例 |
|---|---|
| 查看每月預算 | `預算`、`我的預算`、`budget` |
| 設定・修改每月預算 | `預算 15000`、`預算改 20000`、`budget 15000` |
| 取消每月預算 | `取消預算`、`budget off` |

`預算 0` 不會取消，會提示改傳「取消預算」；`預算外 300` 這類不是整句只有一個金額的訊息仍照一般記帳處理。
